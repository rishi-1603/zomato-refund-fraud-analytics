# Chart renders (chart-only gallery)

These 20 PNGs are the app's Plotly charts, rendered from the figure specifications the running app produces, using the real dataset. They are **not** full-page screenshots, and they do not show the Streamlit layout, filters or KPI cards.

- Generated by `scripts/render_chart_gallery.py` (needs `kaleido==0.2.1`).
- Index: `manifest.json`.
- Charts show the same values as the app at default filters. Re-run the script after any data or chart change.
